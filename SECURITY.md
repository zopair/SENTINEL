# Security Policy

SENTINEL is an early-stage research prototype. The core generator operates on synthetic in-memory data only.

## Reporting
Please do not publish exploitable details involving real systems or third-party infrastructure. Use a private GitHub security advisory when available.

## Safe use
- Test only systems you own or are explicitly authorized to assess.
- Keep experiments local and isolated.
- Deny outbound network access by default.
- Never put production secrets, personal data, or real credentials in decoys.
- Apply CPU, memory, process, storage, and wall-clock limits.
- Stop immediately on suspected escape or contact with an unapproved network.
